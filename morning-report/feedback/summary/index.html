Collect what came in from elsewhere

Feedback filled in on a phone, or on any machine without the data folder, waits at the endpoint until this machine fetches it. Collecting writes it into the folder and then tells the endpoint to forget it — so the folder is the only place any of it lives.

The key stays in this browser

There is no server in this module, so a summary is a call your browser makes straight to the API with your own key. Nothing is proxied through anything of ours, nothing is stored anywhere else, and every payload can be read before it is sent.

What is kept, and what is not The session record holds the ratings, the ticks and the drafted summaries. It does not hold the comments as written — in a group this small a quotation identifies its author — and it does not hold anything about a role, because the roster already records who held which role on that date. Role feedback lives in working/, is handed to the person it is about, and is swept. None of this is summative. It is not a milestone, an evaluation record, or an input to one.
