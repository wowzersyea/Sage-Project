Are we hearing from everyone, and is everyone getting feedback?

This is a scheduling table, not a performance table This file records that a resident served a role on a date. It does not record how the session went — that lives in sessions/ with no names in it, and nothing in this module joins the two. There is no view, export or query here that puts a name next to a score, and none should be added. Be clear-eyed about the limit: anyone holding both files could join them on the date, exactly as anyone holding a call schedule and an evaluation file always could. The protection is that the tool refuses to do it and never surfaces it.

Equity

One row per active resident, sorted by how long it has been since they last took a discussant role — with time away taken out, so an away rotation does not read as neglect. The person at the top is who you draw next. That single sort is the whole feature.
