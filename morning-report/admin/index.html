Administration

Two setup jobs, both done once per machine and then not thought about again. Nobody presenting or discussing a case needs this page.

If report is running, this is already done. Come here when you are setting up a new machine, moving the folder, or adding the second site.

Setting up the data folder

There is no server and no account. The tools read and write JSON files in a folder you choose. Point that folder at a OneDrive-synced location and both sites share state with nothing in between.

  1. Make a folder called MorningReport somewhere OneDrive syncs.
  2. Press Connect data folder in the bar at the top and pick it. Grant read-write.
  3. Do the same once on the other site's machine, pointing at the same synced folder.
MorningReport/
  casebank/            de-identified cases, permanent
  baseline/            the pre-intervention evaluation, permanent — the before picture
  sessions/            de-identified scorecards, permanent
    feedback/          what the group said about the session, permanent
  board-archive/       de-identified board contents, permanent
  working/             identified, ephemeral, CLI and feedback only, swept after 7 days
    feedback/          the role half of the feedback — handed over, then gone
      audio/           recordings, only the ones somebody chose to keep

Folder access needs Chrome or Edge. In any other browser the tools fall back to explicit Download JSON and Load JSON buttons, and the bar says so.

Feedback QR code

Settings has the QR code for the presenter template. Scan it to send feedback from a phone; the board also shows the code at the end of a session.
