How specific does a differential have to be?

An item earns a place on the board only if you can name the test that would refute it. "Hepatitis" in a patient with transaminitis restates the data — it survives every result because it claims nothing.

The four rungs

Worked through one presentation — a teenager with jaundice and transaminases in the 900s.

Restates the data
"Hepatitis"
Not a hypothesis. You already know the liver is inflamed — that is why you are standing there.
Category
"Infectious hepatitis"
Scaffolding, not a list item. This belongs on the framework line above the differential.
Entity
Hepatitis A · EBV · Neonatal HSV
The right level. Each has a distinct test and a distinct action.
Sub-entity
"HAV genotype IB"
Noise. Nothing you do tomorrow morning changes.
1

What test would refute this?

No answer means it is not a hypothesis. "Hepatitis A" has one — IgM anti-HAV, back tomorrow. "Hepatitis" has none, which is exactly the problem.

2

Would tomorrow look different?

Split two items apart only if you would act differently on each. If the plan is identical either way, merge them and move on.

Why this matters on the board A vague item can never be crossed off. It absorbs every result without ever being refuted, so the differential column stops moving and the strike-throughs dry up. Specificity is what makes a list prunable — and pruning is the visible reasoning the whole session is built around.

Practice

Three presentations, each with a mixed list. Sort every item onto a rung. Intended for the senior discussant to run through before report, or for the group in the first few weeks of the new format.
