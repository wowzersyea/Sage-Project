Frameworks

The senior discussant names one of these out loud at 0:11, before listing anything. Pick the framework the case is asking for — not the one you know best. Naming it first is what turns the intern's list into an argument the group can push back on.

One framework, named before the list. The board records whether it was named first, because a framework offered after the list is a label, not a tool. Two frameworks in five minutes is one too many.

If none of them fit

Say so, and say what you are using instead — the board's Framework box takes free text. An honest ad-hoc framework beats forcing the case into infectious, inflammatory, neoplastic because it was the nearest one to hand.
