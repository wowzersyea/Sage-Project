# B7 — The discriminating test named

Decide whether one specific test was named as the thing that separates the leading candidates, with what a positive and a negative would each mean.

## What counts
- "Hip ultrasound, with aspiration if there's an effusion. Effusion plus that CRP and I'm calling ortho tonight. No effusion pushes me to MRI, not back to synovitis."
- The test must be specific, and both directions must be given.

## What does not count
- Ordering a panel. "Let's get labs and imaging" names nothing.
- Naming a test with no interpretation attached.
- Giving only one direction: what a positive means, with nothing about a negative.

## Verdict
`true` only if a single discriminating test was named with both directions stated.
