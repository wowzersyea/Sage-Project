# B5 — A framework named before the list

Decide whether the senior discussant named an organising framework **before** enumerating diagnoses. Order matters, and it is the whole item.

## What counts as a framework
Anatomic by level, anatomic by layer, physiologic, pre / intra / post, mechanistic category, age-anchored, tempo, triage-based — or any other explicit organising scheme stated as a scheme.

Example of naming it first: "Let me take this by layer, because that's what the imaging will sort out. Skin and soft tissue — no cellulitis, off. Joint — septic arthritis and transient synovitis, both live. Bone — osteomyelitis, live."

## What does not count
- A better list with no scheme named.
- A scheme mentioned only after the diagnoses have been enumerated. If the list came first, the answer is `false` even if the word "framework" appears later.
- The word "framework" used without an actual organising principle.

## Verdict
`true` only if the scheme was named before the enumeration began. State in your reasoning where each occurred, with timestamps, so the ordering can be checked.
